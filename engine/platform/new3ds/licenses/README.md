# 3DS runtime notices

The package preserves the engine's notices and those of static libraries used
by the toolchain. These files do not include commercial game data.

- libctru 2.7.0: https://github.com/devkitPro/libctru/blob/v2.7.0/README.md
- GCC Runtime Library Exception 3.1 and GPL 3: https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html
- Newlib 4.6.0.20260123: https://sourceware.org/pub/newlib/newlib-4.6.0.20260123.tar.gz

The Newlib notice was extracted from the archive with SHA256
`6ff27e3bf022666f43f7802255be680eeff722ac181b1725d21e2e8318604ee3`,
matching the value recorded by the official devkitPro package:
https://github.com/devkitPro/pacman-packages/blob/master/devkitarm/newlib/PKGBUILD
