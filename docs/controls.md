# Controls

On PC, use the mouse and keyboard. Click the interface buttons to open modes,
select Sims and choose actions. See the [keyboard shortcuts](keyboard-controls.md).

## Switch, Vita and Android with a controller

The following mapping is implemented in current builds. On Android, it is used
when a compatible controller is connected; touch remains available.
Confirmation on the devices is still in progress. Check the
[platform status](status.md#other-platforms).

| Control | Action |
| --- | --- |
| Left stick | Move the camera. |
| Right stick | Move the cursor. |
| Right trigger: R2, RT or ZR | Click at the cursor. Hold to drag. |
| Left trigger: L2, LT or ZL | Select the next Sim and center the camera on them. |
| L/R or L1/R1 | Rotate the camera or the object being placed. |
| Bottom face button | Open Live Mode. |
| Left face button | Open Buy Mode. |
| Top face button | Open Build Mode. |
| Right face button | Remove the held object or go back, depending on the screen. |
| Start or `+` | Pause or resume. |
| D-pad up / down | Zoom in / out. |
| D-pad left / right | Normal / fast speed. |
| Select or `−` + D-pad right | Maximum speed. |
| Click left / right stick | Go down / up one floor. |

Face buttons are described by **position** because their labels differ between
controllers. On a PlayStation controller, bottom, left, top and right correspond
to cross, square, triangle and circle.

On a touch screen, tap directly on what you want to select. The black bars at
the sides are outside the game area.

### Vita rear touchpad

- **Left half:** works as L2. A touch selects the next Sim and centers the camera.
- **Right half:** works as R2. Keep your finger on it to hold the click and use
  the right stick to move the cursor. Lift your finger to release.
- **Select + D-pad down / up:** go down / up one floor, since the Vita sticks
  do not have a click action.

The half where your finger first touched keeps its role until you lift it,
even if you cross the middle of the panel. The front screen remains available
for direct selection. The physical L/R buttons remain free for rotation.

### Current limits

On Switch, release the triggers before disconnecting the controller: the game
may not be notified correctly when it is physically disconnected. Suspend,
resume and different Android controller models still need their own tests.

## New Nintendo 3DS

For now, New 3DS keeps the two-screen interface and controls from the Sims3DS
base. It **does not use the table above**. With a house open:

| Control | Action |
| --- | --- |
| Lower screen | Select buttons and options by touch. |
| Circle Pad | Move the cursor; reaching the edge also moves the camera. |
| C-Stick | Move the camera. |
| A | Select at the cursor. |
| L / R | Rotate the camera. |
| D-pad up / down | Zoom in / out. |
| D-pad left / right, in Live Mode | Select the previous / next family member. |
| ZL / ZR | Go down / up one floor. |
| Select | Cycle wall visibility. |
| X, in Live Mode | Pause or resume. |
| Y, in Live Mode | Center on the selected Sim. |
| Start | Open or close Options. |

Some buttons change function in Create a Family, Buy Mode and Build Mode.
Also use the controls shown on the screen. Installation details and limits are
in the [platform guide](installation.md#new-nintendo-3ds).
