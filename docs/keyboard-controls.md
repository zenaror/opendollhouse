# Keyboard shortcuts

These shortcuts are available in the PC interface with a house open.
In dialogs and name fields, keys are used to respond and type.

| Key | Action |
| --- | --- |
| `1`, `2`, `3` | Normal, fast and maximum speed, in Live Mode. |
| `P` or the key above Tab | Pause or resume at the last speed, in Live Mode. |
| `F1` | Open Live Mode. |
| `F2` | Open Buy Mode. Press again to switch between categories by function or room. |
| `F3` | Open Build Mode. |
| `F5` | Open Options. |
| Arrow keys | Move the camera. |
| `+` / `-` | Zoom in or out. The numeric keypad also works. |
| Comma / period | Rotate the camera or the object being placed. |
| `Page Up` / `Page Down` | Go up or down one floor. |
| `Home` / `End` | Raise or lower wall visibility. |
| Space or `N` | Select the next family member, in Live Mode. |
| Enter | Center on the selected Sim, in Live Mode. |
| `Z` / `X` | Go to the previous or next Buy or Build catalog page. |
| Delete | Sell or remove the held object, depending on the context. |
| Esc | Cancel or close the current selection, depending on the screen. |

Use the interface buttons to save and quit. `Ctrl+S`, `Q`, `Ctrl+Shift+C` and
photography with `F4` are not yet available as shortcuts.

See also the [console and Android controls](controls.md).
