# Situação do motor nativo

Este endereço é mantido para compatibilidade com referências antigas.
O estado público das funcionalidades e suas limitações está na
[matriz de funcionalidades](playable-feature-matrix.md).

- O motor C/C++ é o caminho de desenvolvimento; Simitone/FreeSO são referências.
- Há cenários limitados de interação, famílias, desenho, áudio e salvamento no Linux.
- Paridade com o jogo completo, interface original, expansões e ports permanecem incompletos.
- O [plano nativo](native-port-plan.md) e o [inventário de migração](migration/README.md)
  descrevem as entregas e critérios ainda necessários.

Para compilar e usar, consulte o [README](../README.md). Este documento não
contém instruções de sessão ou dados específicos de uma máquina.
