# Shared CFP provider for the scene renderer

The renderer can now sample the exact animation selected by a multi-FAR
`AnimationCatalog`, while retaining its base FAR for the rig, appearances and
meshes. This is a prerequisite for showing the constructed person host's Main
animations, whose headers and CFP can live outside the base Animation FAR.
The person host and a playable Linux app are not connected by this unit.

## Contract

`AnimationCatalog::decode(const AnimationHeader&)` accepts the live immutable
header returned by that catalog, including an aliasing Playback handle. Its
weak identity registry maps that object directly to the indexed BCF resource
and the selected CFP provenance (source and entry). It does not search again by
internal animation name. A copied header or one owned by another catalog
rejects even when its values and names match. The existing string-based
resolve/decode APIs and ambiguity rules remain available.

`SceneRenderer(config, SceneCfpResolver)` uses the optional provider as the
authoritative source of CFP planes. A catalog adapter calls `decode(selected)`
and returns an aliasing `shared_ptr` to `CatalogDecoded::planes`. The renderer
keeps that handle through the draw, without copying the planes or retaining a
second decoded cache. The catalog remains responsible for its live-handle
budgets and LRU. Its existing per-selected-animation accounting policy is
unchanged; this does not claim global CFP deduplication across different
animation headers.

A null result or provider failure rejects; it never falls back to a CFP in
the rig FAR. `sample_pose` checks the seven plane lengths, finite values,
motion ranges and animation limits before sampling. The provider must pair
the planes with the exact selected header and must not reenter the renderer.
Bind pose does not call it. The renderer's `cache_clips()` and `cache_samples()`
report only its own legacy cache and stay zero in provider mode; a host using
the provider must report the catalog usage separately.

Without a provider, the previous folded xskill lookup, renderer cache and
`SceneConfig.animation_far` behavior are unchanged. Rig/appearance/mesh
selection still comes from that one explicitly supplied base archive.

## Matrix and results — 2026-10-20

All resources below are FAR/BCF/CFP/rig/mesh/texture fixtures generated by the
tests. No commercial file or original executable was read by these gates.

| Named case | Verified behavior | Debug | ASan/UBSan |
|---|---|---|---|
| legacy-and-multifar-pixels-depth | Header and CFP in separate FARs; frames 0, 0.5 and 1 equal legacy combined-FAR RGB/depth and raster counts; visible animation changes | pass | pass |
| selected-header-identity | Copy and foreign-catalog headers reject without decoding; the live header retains exact BCF/CFP source/entry | pass | pass |
| missing-cfp-no-legacy-fallback | Missing provider CFP rejects even when the rig FAR has a matching local CFP | pass | pass |
| ambiguous-source-refused | Duplicate CFP basenames reject before publishing header/cache state | pass | pass |
| malformed-cfp-rolls-back-ledger | Truncated external CFP releases decoded metadata/sample charges | pass | pass |
| sample-budget-and-shared-handles | Limit13 rejects a14-sample clip; exact14 budget supports20 draws, same decoded handle and no renderer cache; pinned handles retain their charge | pass | pass |
| null-and-mismatched-provider-refused | Null or wrong-length planes reject without populating the legacy cache | pass | pass |
| validation-before-provider-and-bind-pose | Bind pose avoids provider; invalid frame rejects before calling it | pass | pass |

Each configuration ran **4/4 selected CTests**, with no failure, skip, blocked
or not-run case inside those gates. New `scene_cfp_provider`: **8/8 named
cases, 52 checks** per configuration. Companion gates:
`animation_catalog` (196 checks), `scene_hand_gestures` (74 checks), and
`reusable_scene_host` (legacy animated RGB/depth compared byte-for-byte with
the explicit render CLI). Pixel equality uses the same renderer/rasterizer;
it is a regression control, not an independent original-graphics oracle.

Builds are separate Debug directories, both configured with `ODH_X11=OFF` and
`ODH_SDL_AUDIO=OFF`. The sanitizer build enables `ODH_SANITIZERS=ON`;
`ASAN_OPTIONS=detect_leaks=0` and `UBSAN_OPTIONS=halt_on_error=1` were used.
Leak detection was not performed. Gate logs and JUnit are retained under
`reports/scene-cfp-provider-20261020/`; `validation.json` records source,
binary and evidence hashes. Other historical CTests were not rerun.

Not run: person/Main rendered frames, native-data multi-FAR rendering,
window/backend delivery, original visual equivalence, full lot gameplay and
console tests. The next host integration must keep World/VM ticks, hands and
Playback identity authoritative, and must distinguish an explicit presentation
anchor from a restored runtime position.
